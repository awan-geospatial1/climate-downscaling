Setup
Connect this app to your Drive
connected
  1. In Google Cloud Console, create or select a project and enable the Google Drive API.
  2. Configure the OAuth consent screen as External + Testing, and add your own Google account under Test users.
  3. Create an OAuth 2.0 Client ID (Web application). Add the exact URL you'll open this file from as an Authorized JavaScript origin — e.g. http://localhost:8000. file:// URLs won't work with Google sign-in.
  4. Paste that client ID into CLIENT_ID near the top of this file's <script> tag.
  5. Serve the file locally, e.g. python3 -m http.server 8000, then open http://localhost:8000/index.html.
  6. Open colab_runner.ipynb in Colab, run every cell, authorize Drive + Earth Engine, and leave that tab open — it polls for jobs every 10s.
This uses the full drive scope rather than drive.file, because the web app and the notebook both need to see the same job folder regardless of which one wrote each file. Keep this for personal or small-team use — publishing it to the public would require Google's OAuth verification review.
